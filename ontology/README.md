# Life-event ontology

`event-types.yaml` is the controlled vocabulary used by the v0.1 validator.

A proposed event type must define:

- a stable namespaced identifier;
- a domain;
- a testable inclusion definition;
- at least one example;
- at least one exclusion or boundary case;
- any required attributes;
- privacy and leakage risks when applicable.

The vocabulary should not silently encode one culture's life sequence as universal. Historical, regional, and institutional variation should be documented in proposals.
